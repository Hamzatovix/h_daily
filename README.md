# HAMZATOVIC daily — пакет для сайта

Эта папка — будущий репозиторий сайта журнала. В ней уже лежит всё, что нужно Claude Code, чтобы собрать сайт по нашему дизайну, а не придумывать свой.

## Что внутри

| Папка / файл | Что это |
| --- | --- |
| `CLAUDE.md` | Правила проекта для Claude Code. Он читает их сам в начале каждой сессии |
| `docs/roadmap.md` | План по шагам и готовые формулировки задач — копируйте по одной |
| `docs/components.md` | Как работает каждый элемент: рамка, клапаны, сноски, карточки, ночь |
| `docs/pages.md` | Адреса и состав страниц |
| `docs/content-model.md` | Как устроены тексты: поля шапки статьи и тома |
| `docs/quality.md` | Чеклист качества перед запуском |
| `design/brandbook/` | Брендбук: правила, голос, иллюстрации, компоненты |
| `design/tokens.json` | Цвета, шрифты, отступы — исходник |
| `design/screens/` | Снимки макетов для сверки: главная, четыре статьи, телефон, ночь, брендбук |
| `src/styles/tokens.css` | Те же токены готовыми CSS-переменными (день, ночь, цвет тома) |
| `src/content/` | Том 1 и его тексты в Markdown |
| `public/covers/` | Обложки тома 1 и ленты: WebP для сайта, SVG-исходники |
| `public/brand/` | Логотип во всех версиях, монограмма, фавикон, точка |

## Как начать

1. Установите Node.js (версия LTS) и Git, если их ещё нет.
2. Создайте пустой репозиторий на GitHub и положите туда эту папку.
3. Откройте папку в Claude Code.
4. Скопируйте первую задачу из `docs/roadmap.md` (шаг 1) и дождитесь плана. Если план понятен, разрешите выполнять.
5. После каждого шага откройте сайт в браузере (`npm run dev`) и сравните со снимком из `design/screens/`. Нравится — пусть делает коммит и переходит к следующему шагу.

## Что важно помнить

- Тексты статей правит только редакция. Claude Code их не переписывает.
- Ваша рубрика Judge me by cover пока стоит заглушкой (`src/content/articles/tome-1/05-judge-me-by-cover.md`, статус `draft`). Когда текст будет готов, он пишется в этот файл, статус меняется на `published`.
- В клапанах «Слушать» пока нет ссылок на песни: поле `href` пустое. Добавьте, когда решите, куда вести (Яндекс Музыка, Apple Music и т. п.).
- Дата выхода тома (`publishedAt` в `src/content/tomes/tome-1.md`) пока не задана.
- Хостинг можно выбрать в самом конце: сайт статический и разместится где угодно.
