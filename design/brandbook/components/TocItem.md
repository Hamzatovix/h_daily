# TocItem

Пункт оглавления тома: номер в порядке чтения, название, о чём материал, автор и время.

- Номер набран `flap-label`, название — `card-title` 25px, описание — курсив 16px, справа автор и минуты 15px.
- Пункты разделены линейками `hairline` цвета `ink`. Номера есть только здесь, потому что том читается по порядку.
- Под оглавлением стоит кнопка «Читать том с начала»: заливка `ink`, текст `paper`, справа точка `tome`.
- Нужно передать: порядковый номер, название, описание в одну строку, автора, минуты.
