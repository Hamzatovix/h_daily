# Flap

Левый клапан статьи: контекст к тексту, который хочется держать под рукой во время чтения.

- Фон `flap`, справа пунктир `hairline` цвета `ink`, поля `space-48` / `space-32`. Ширина — 3 колонки сетки.
- Метки набраны `flap-label` (Dela), текст — `flap-text`. Пункты:
  - «Слушать» — для музыки, с круглой кнопкой воспроизведения;
  - «Смотреть» — для кино;
  - «Читать» — для книг;
  - «Голос» или другой короткий факт;
  - «Читать рядом»;
  - внизу «Автор».
- На телефоне клапан свёрнут в строку с «+» и раскрывается по нажатию.
- Нужно передать: 2–4 пункта (метка + текст или ссылка) и тип материала.
- Нельзя: превращать клапан в рекламу, ставить больше четырёх пунктов, менять фон на цвет тома.
