# План работы и готовые задачи для Claude Code

Каждый шаг — отдельная задача. В конце каждого шага: открыть страницу в браузере, сравнить со снимком, пройти нужные пункты `quality.md`, коммит. Формулировки ниже можно копировать в Claude Code как есть.

Хостинг пока не выбран. Сайт статический, так что выбор ни на что в коде не влияет.

---

## Этап 1. Основа

**Шаг 1. Проект.**
> Прочитай CLAUDE.md и docs/. Создай в этой папке проект Astro (минимальный шаблон, TypeScript strict), не трогая существующие папки design/, docs/, public/, src/content/, src/styles/. Подключи шрифты @fontsource/dela-gothic-one и @fontsource/literata (кириллица и латиница) и src/styles/tokens.css. Сделай базовый layout: html lang="ru", data-tome из коллекции томов, инлайн-скрипт темы до отрисовки, рамка цвета тома. Пока без компонентов. Сначала покажи план в режиме плана.

**Шаг 2. Контент.**
> Создай src/content.config.ts по docs/content-model.md. Добейся, чтобы astro check проходил на всех файлах в src/content/. Выведи на временной странице список статей тома 1 с полями — проверим, что всё читается.

**Шаг 3. Обработка текста.**
> Сделай цепочку обработки Markdown из docs/content-model.md: типограф (typograf, ru), плагин сносок на полях, плагин цитаты (с ошибкой сборки, если цитата не найдена), lede для первого абзаца и EndMark для последнего. Покажи результат на статье «Белый кит с Мотт-стрит» без оформления.

## Этап 2. Статья — сердце журнала

**Шаг 4. Статья на компьютере.**
> Собери страницу статьи по docs/pages.md и docs/components.md: Header, ArticleHero, Flap, колонка текста, Sidenote со сносками и цитатой, EndMark, NextInTome, короткий Footer. Сверяй с design/screens/02-article-belyj-kit.jpg, 02a и 02b на ширине 1440. Потом проверь остальные три статьи по 03, 04, 05.

**Шаг 5. Рамка-прогресс.**
> Сделай TomeFrame с прогрессом чтения по docs/components.md: на компьютере верхний край и «ещё N минут», на телефоне — вся рамка по часовой стрелке. Сначала CSS scroll-driven animations, иначе маленький скрипт. Учти prefers-reduced-motion.

**Шаг 6. Статья на телефоне.**
> Адаптируй статью для телефона по design/screens/06-mobile.jpg: шапка 56px, обложка обрезана, клапан свёрнут в строку на details/summary, сноски раскрываются под строкой, цитата на полях скрыта. Проверь на 320, 390, 768.

**Шаг 7. Ночь.**
> Сделай ночную тему и ThemeToggle по docs/components.md. Сверь статью ночью с design/screens/07-night.jpg. Убедись, что обложки не перекрашиваются и нет вспышки белого при загрузке ночью.

## Этап 3. Том и остальные страницы

**Шаг 8. Главная тома.**
> Собери главную тома по docs/pages.md и design/screens/01-tome-home.jpg: первый экран с обложкой и оглавлением, «В томе» с пятью карточками (пятая — JudgeCard), «Лента» с пустыми местами, рубрики главреда, полка, подвал. Потом телефонная версия по 06-mobile.jpg.

**Шаг 9. Лента, Тома, О журнале, 404.**
> Сделай страницы без макета строго из существующих компонентов и токенов, по docs/pages.md. Текст «О журнале» — заглушка с TODO, кроме обязательной строки про редакционный псевдоним.

**Шаг 10. SEO и сервисное.**
> RSS, карта сайта, Open Graph и JSON-LD Article по docs/pages.md. Превью — обложки материалов. Черновики никуда не попадают.

**Шаг 11. Проверка перед запуском.**
> Пройди весь docs/quality.md на всех страницах. Исправь всё, что не проходит. Отчитайся списком: что проверено, что исправлено, что осталось.

## Этап 4. После запуска (по одному, когда понадобится)

- **Карточки для соцсетей:** генерация превью с цитатой и обложкой при сборке (Satori + resvg). Satori не читает WOFF2 — шрифты для него нужны в TTF/OTF/WOFF.
- **«Поделиться цитатой»:** выделенная фраза или цитата на полях → картинка-карточка в фирменном стиле.
- **Плеер** в клапане «Слушать» (ссылки на песни редакция добавит в `href`).
- **Поиск** по всем материалам (Pagefind).
- **«Продолжить с места»**: запоминать позицию чтения в статье.
- **Рассылка** о выходе нового тома.
- **Редакторская панель** Keystatic поверх тех же файлов в `src/content/`.
