# Чеклист качества

Сайт журнала проверяется не «работает ли», а «выглядит и читается ли как издание». Перед каждым крупным шагом и перед запуском пройти весь список.

## Совпадение с макетом

- [ ] Страница на 1440 совпадает со снимком из `design/screens/`: сетка, размеры шрифтов, отступы, линейки.
- [ ] На 390 — со снимком `06-mobile.jpg`. Нет горизонтальной прокрутки ни на одной ширине от 320 до 1920.
- [ ] Ночью — со снимком `07-night.jpg`. Обложки не перекрашены.
- [ ] На странице нет цветов вне токенов. Поиск по коду: ни одного `#rrggbb` вне `tokens.css` (кроме SVG логотипа).
- [ ] Нет скруглений, теней и градиентов (кроме затухания-маски, если оно в макете).

## Типографика

- [ ] Типограф отработал: нет висячих предлогов «в», «и», «с», «к» в конце строки; тире с неразрывным пробелом перед ним; «1936 году» не разрывается.
- [ ] Переносы включены в колонке статьи, заголовки без переносов.
- [ ] Ширина колонки текста ≤ 640px, 60–70 знаков в строке.
- [ ] Первый абзац — `lede` без красной строки, дальше красная строка 1,6em, без пустых строк между абзацами.
- [ ] Цифры старого стиля в тексте.
- [ ] Длинные заголовки не вылезают за колонку ни на одной ширине.
- [ ] Шрифты загружаются без мигания: `font-display: swap`, предзагрузка двух основных начертаний, метрики запасного шрифта подогнаны (`size-adjust`), чтобы текст не прыгал.

## Скорость

- [ ] Lighthouse на телефоне: Performance, Accessibility, Best Practices, SEO — 95+ (цель — 100).
- [ ] CLS = 0: у всех изображений заданы размеры, у обложек `aspect-ratio: 3/4`.
- [ ] LCP < 2 с на телефоне: обложка первого экрана — `fetchpriority="high"`, остальные — `loading="lazy"`.
- [ ] JS на странице статьи — только рамка, переключатель темы, раскрытие на телефоне. Суммарно — единицы килобайт.

## Доступность

- [ ] Один `<h1>` на странице, порядок заголовков без пропусков.
- [ ] Всё доступно с клавиатуры: клапан, сноски, переключатель ночи, кнопка «Поделиться цитатой». Фокус виден.
- [ ] У обложек осмысленный `alt` (`coverAlt`), у декоративных SVG — `aria-hidden`.
- [ ] Сноски: ссылка из текста ведёт к сноске и обратно, экранный диктор читает их как сноски.
- [ ] Учитывается `prefers-reduced-motion`.
- [ ] Контраст — только сочетания из `tokens.json`.

## Содержание и превью

- [ ] Тексты совпадают с `src/content/` слово в слово, ничего не потеряно при обработке (сноски, курсив, кавычки).
- [ ] Цитата на полях совпадает с подчёркнутой фразой в тексте.
- [ ] Превью ссылки в Telegram и ВКонтакте: картинка, заголовок, описание. Проверить живыми ссылками после выкладки.
- [ ] RSS открывается в читалке, в нём полные тексты или описания и обложки.
- [ ] Черновик рубрики главреда не попадает ни в RSS, ни в карту сайта, ни отдельной страницей.

## Печать

- [ ] Статья печатается на A4: без шапки, рамки и клапанов, сноски — в конце, адрес статьи внизу.
